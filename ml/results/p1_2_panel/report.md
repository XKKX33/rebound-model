## 二、面板的列

| 列 | 含义 |
|---|---|
| `trade_date`、`ts_code` | 信号日、股票代码 |
| `di` | 信号日在全部交易日里的下标（从 0 起），用于按“第几个交易日”切分和对齐 |
| 28 个特征 | `pct_chg`、`r1`、`r5`、`r10`、`r20`、`r60`、`r120`、`from_low60`、`from_high60`、`dev_ma5`、`dev_ma20`、`dev_ma60`、`ma20_gt_ma60`、`ma20_slope5`、`ma60_slope10`、`dd20`、`vol5`、`vol20`、`amp20`、`launch10`、`up_days10`、`max_up20`、`limit_up_today`、`limit_up20`、`dif_ratio`、`hist_ratio`、`rank_r20`、`rank_r60` |
| `ret_o1o5` | T+1 开盘买、T+5 开盘卖的复权收益（卖不出时顺延）；空 = 无效 |
| `exit_di`、`exit_date` | 实际卖出日的下标和日期（-1 / 空 = 无效） |
| `in_cap70` | 是否也在限 70 元版的池里 |
| `label_pct` | 当天池内收益的百分位（**只用于评估**；训练标签另按训练截止日重排，防泄漏） |
| `excess_o1o5` | 收益减去当天池子的平均收益（评估 Top-K 超额用） |

- 仓库文档说明过：按年分段算和单日算的起点不同，DuckDB 窗口求和顺序、MACD 指数均线的起点不同，会差在 float32 的末位；
  `ma20_gt_ma60` 在两条均线数学上相等时可能翻转。所以判断标准是“差在 1e-5 量级以内、准入池完全一致”。

### 标签：抽 2000 个没有顺延的样本，直接用 SQL 算 T+1 开盘 → T+5 开盘的复权收益

- 对上 2000 / 2000 行，最大绝对差 0.00e+00。

### 特征缺失率（%）

28 个特征在准入池里**没有缺失**：准入池要求至少 150 根日线，而最长的窗口是 120 根（`r120`）、MACD 预热 33 根，进池时所有窗口都已填满。
