# 3.3 XGBoost 复现基准（验证段）

- 运行：`python -X utf8 -m ml.train_eval xgb_repro_F28`，报告 `python -X utf8 -m ml.p3_baselines`
- 配置：仓库原参数 `rebound.params.PARAMS`（{'n_estimators': 300, 'max_depth': 5, 'learning_rate': 0.05, 'subsample': 0.8, 'colsample_bytree': 0.8, 'tree_method': 'hist'}），种子 [0, 1, 2]，16 线程；28 个原特征；
  训练 1,924,614 行（2013-08 ~ 2020-12，卖出日早于 2021-01-04），验证段 709,113 行；训练 36 秒

## 一、验收（PREREG 2.5、补充登记二第 8 条）

| 项目 | 数值 |
|---|---|
| 作者记录的 Rank IC | 约 0.095（开发期和留出期，每月重训） |
| 我们的验证段 Rank IC（3 个种子平均的分数） | **0.0946** |
| 差距 | -0.0004（容许 ±0.02） |
| 结论 | **通过** |

## 二、和作者的训练代码逐项核对

用仓库自己的 `training_set`、分块 `_Batches`、`booster_params` 在同一重训日（2021-01-04）重训 3 个种子，与统一接口训出来的模型对比：

| 项目 | 结果 |
|---|---|
| 训练行完全相同 | True |
| 训练标签完全相同 | True |
| 两边分数的相关系数（逐种子） | 1.000000 / 1.000000 / 1.000000 |
| 两边分数的最大绝对差（逐种子） | 0.00e+00 / 0.00e+00 / 0.00e+00 |
| 验证段 IC：仓库流程 / 统一接口 | 0.0946 / 0.0946 |

两边分数**逐位相同**（最大差 0）：统一接口训出来的模型和作者的训练代码训出来的完全一样。IC 末位的微小差别只是因为我们的分数存成 float32 后再平均。

另：作者的 0.095 是**每月重训**得到的（仓库每个月第一个交易日用此前全部数据重训一次；“每季度 / 每年”只是从月度模型里挑着用）。
我们的协议 A 在验证段两年里**不重训**，IC 仍然对上，说明这套特征和参数的排序能力在两年内比较稳定。

## 四、和反转因子比（按月整块重抽 95% 区间）

| 指标 | XGBoost − 反转因子 | 95% 区间 |
|---|---|---|
| 逐日 IC | +0.0546 | [+0.0352, +0.0747] |
| 前 30 名超额（%） | +0.494 | [+0.130, +0.876] |

两个区间都不含 0：XGBoost 在 28 个特征上的排序能力明显强于单因子反转；而且反转因子前 6 名的超额是负的（−0.56%），
XGBoost 的前 6 名是正的（+0.35%），10 组也完全单调——组合多个特征后，最靠前的那一小撮不再“跌了还跌”。
