# 持股规则搜索（本金 20.0 万）

4 种重训频率（每年、每半年、每季度、每月）× 150 条规则 = 600 组；计分 2015-01-13 ~ 2026-10-19。印花税按现行 0.05%（real），佣金万五最低 5 元，一手取整。超额 = 每天（组合 − 准入池）收益的均值 × 242，区间按月重抽；信息比率 = 超额均值 / 超额波动（年化）。规则网格和选法见 PREREG.md 补充登记一至三。

## 结论

- 滚动检验（2017–2026 每年年初只用之前的数据选规则，拼成样本外）里最好的选法是**信息比率**：样本外超额 +25.3 [+15.8, +35.1]，年化 +17.8%，最大回撤 -29.2%。逐年选中的规则：2017：每月 DB-K15-b3；2018–2019：每月 DB-K30-b8；2020–2021：每月 DB-K30-b4；2022–2023：每月 DB-K30-b8；2024：每月 DB-K20-b16；2025–2026：每月 DB-K30-b8。
  - 同一段比原方案多 +13.2 [+4.5, +21.7]（逐日配对）。
- 用全部数据按这个选法，推荐 **每月重训 + DB-K30-b8（最多 30 只，排名掉出前 240 名才卖）**：全期超额 +31.7 [+23.3, +40.4]，年化 +29.8%，最大回撤 -47.0%，本金 20.0 万 变成 442.0 万；每天买 6.83 只，每只拿 4.4 天，费用每年约 7.5%。
- 登记时定的选法（平滑后超额）推荐 每月重训 + DB-K3-b4（最多 3 只，排名掉出前 12 名才卖）：全期超额 +46.0，但最大回撤 -57.1%；它的滚动样本外只有 +13.2 [-7.5, +35.5]，年化 +0.3%，回撤 -79.8%。不推荐。
  - 选法是看了滚动结果才定的（四选一），样本外数字会偏乐观一点。
- 按超额排的前 12 名里，10 组平均只拿 ≤ 3.5 只，最大回撤 -72% ~ -48%。集中持仓的超额靠少数几只票，哪组领先每年都在换，事先挑不中；分散的组超额低一些但年年稳，事先挑得中。
- 过拟合概率 PBO（按超额挑）= 0.28：样本内第一的那组，样本内超额 +52.1，到样本外平均 +29.3（所有组样本外的中位数 +24.9）。PBO 0.5 左右说明挑出来的和随手拿一组差不多，越接近 0 越可信。
- 过拟合概率 PBO（按信息比率挑）= 0.00：样本内第一的那组，样本内超额 +34.1，到样本外平均 +29.2（所有组样本外的中位数 +24.9）。PBO 0.5 左右说明挑出来的和随手拿一组差不多，越接近 0 越可信。
- 多重比较（现实检验）：600 组里最好那组超额 +46.0，p = 0.004；校正后仍显著 > 0 的 69 组。
  - 跑赢原方案：p = 0.058，校正后显著跑赢的 0 组（门槛 +31.8）。
- 同一段对照：事后看全期最好的一组 超额 +39.1、年化 +32.5%、回撤 -41.1%；全部组的平均 超额 +20.1、年化 +11.5%、回撤 -37.5%；原方案（每年重训 + FH-K6） 超额 +12.2、年化 +3.2%、回撤 -50.3%。
