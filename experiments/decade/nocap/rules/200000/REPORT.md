# 持股规则搜索（本金 20.0 万）

4 种重训频率（每年、每半年、每季度、每月）× 150 条规则 = 600 组；计分 2015-01-13 ~ 2026-10-19。印花税按现行 0.05%（real），佣金万五最低 5 元，一手取整。超额 = 每天（组合 − 准入池）收益的均值 × 242，区间按月重抽；信息比率 = 超额均值 / 超额波动（年化）。规则网格和选法见 PREREG.md 补充登记一至三。

## 结论

- 滚动检验（2017–2026 每年年初只用之前的数据选规则，拼成样本外）里最好的选法是**信息比率**：样本外超额 +26.1 [+16.9, +35.7]，年化 +19.1%，最大回撤 -30.4%。逐年选中的规则：2017：每月 DB-K30-b4；2018：每月 DB-K30-b6；2019–2021：每月 DB-K30-b4；2022：每月 DB-K30-b6；2023–2026：每季度 DB-K30-b4。
  - 同一段比原方案多 +11.4 [+2.5, +20.3]（逐日配对）。
- 用全部数据按这个选法，推荐 **每季度重训 + DB-K30-b4（最多 30 只，排名掉出前 120 名才卖）**：全期超额 +32.4 [+23.4, +41.5]，年化 +31.0%，最大回撤 -53.8%，本金 20.0 万 变成 492.7 万；每天买 9.66 只，每只拿 3.1 天，费用每年约 10.4%。
- 登记时定的选法（平滑后超额）推荐 每半年重训 + DB-K1-b16（最多 1 只，排名掉出前 16 名才卖）：全期超额 +41.1，但最大回撤 -77.0%；它的滚动样本外只有 +21.6 [-5.3, +52.4]，年化 +8.0%，回撤 -67.8%。不推荐。
  - 选法是看了滚动结果才定的（四选一），样本外数字会偏乐观一点。
- 按超额排的前 12 名里，12 组平均只拿 ≤ 3.5 只，最大回撤 -77% ~ -63%。集中持仓的超额靠少数几只票，哪组领先每年都在换，事先挑不中；分散的组超额低一些但年年稳，事先挑得中。
- 过拟合概率 PBO（按超额挑）= 0.40：样本内第一的那组，样本内超额 +52.5，到样本外平均 +27.7（所有组样本外的中位数 +26.4）。PBO 0.5 左右说明挑出来的和随手拿一组差不多，越接近 0 越可信。
- 过拟合概率 PBO（按信息比率挑）= 0.01：样本内第一的那组，样本内超额 +34.7，到样本外平均 +29.5（所有组样本外的中位数 +26.4）。PBO 0.5 左右说明挑出来的和随手拿一组差不多，越接近 0 越可信。
- 多重比较（现实检验）：600 组里最好那组超额 +45.1，p = 0.003；校正后仍显著 > 0 的 122 组。
  - 跑赢原方案：p = 0.094，校正后显著跑赢的 0 组（门槛 +30.8）。
- 同一段对照：事后看全期最好的一组 超额 +37.4、年化 +30.9%、回撤 -43.0%；全部组的平均 超额 +21.8、年化 +13.9%、回撤 -36.0%；原方案（每年重训 + FH-K6） 超额 +14.7、年化 +6.1%、回撤 -47.5%。
