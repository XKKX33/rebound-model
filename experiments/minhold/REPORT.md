# 最少持有天数：只改持股规则的十年回测

模型和打分不动（十年实验存的每月重训 CPU 版打分，标签 o1o5：T+1 开盘买、T+5 开盘卖，拿 4 天）。只改 DB 规则的卖出条件：排名掉出 b·K 名的票，要拿满 N 个开市日才卖（N = 1 是现在的规则）。准入池不限价，剔除 < 2 元和退市整理期；佣金万五最低 5 元，印花税 0.05%，一手取整；计分 2015-01-13 ~ 2026-10-19。超额 = 每天（组合 − 准入池）收益的均值 × 242，区间按月重抽 95%；"比 N = 1" = 同一条规则两个 N 逐日收益之差的年化。预注册见 PREREG.md。

## 结论

- **2 万（DB-K2-b6）：N = 4 比现在（N = 1）分不出。**年化 +38.8% → +15.8%，超额 +41.5 → +23.8；逐日配对差 -17.8 [-32.3, -2.8]；四个起点最差年化 +22.3% → +9.9%；90 条 DB 规则里 N = 4 超额更高的 42/90 条。平均每只拿 2.3 → 4.9 天，费用每年 13.5% → 7.0%：省下的费用抵不上少赚的。
  - 参照规则 DB-K3-b16：N = 4 比 N = 1 逐日配对差 -12.2 [-25.6, +0.4]，四个起点最差年化 +23.4% → +8.4%。
  - 事后拆分（看过结果才加，不改结论）：2 万 N = 4 比 N = 1，K 1–3：2/27 条更高，中位数 -8.6（N = 1 时超额中位数 +36.2）；K 4–8：9/27 条更高，中位数 -2.7（N = 1 时超额中位数 +29.9）；K 10–30：31/36 条更高，中位数 +1.7（N = 1 时超额中位数 -8.9）；N = 1 时四个起点都赚的：4/32 条更高，中位数 -8.0（N = 1 时超额中位数 +35.8）。比例被 K ≥ 10 的规则拉高：它们在 2 万本金下被最低佣金拖成负超额，拿久一点少交易、少亏一点；2 万真正能用的 K 1–3 和换起点都赚的那些规则，N = 4 几乎都更差。
- **20 万（DB-K30-b4）：N = 4 比现在（N = 1）更差。**年化 +28.9% → +24.0%，超额 +30.8 → +26.8；逐日配对差 -3.9 [-7.8, -0.3]；四个起点最差年化 +8.3% → +12.1%；90 条 DB 规则里 N = 4 超额更高的 11/90 条。平均每只拿 3.2 → 5.7 天，费用每年 10.5% → 6.1%：省下的费用抵不上少赚的。
  - 参照规则 DB-K30-b8：N = 4 比 N = 1 逐日配对差 -3.5 [-7.3, +0.3]，四个起点最差年化 +14.1% → +14.7%。
- 2 万 全网格，超额比 N = 1 的变化（中位数）：N = 2 +0.5（61/90 条更高），N = 3 +0.5（50/90 条更高），N = 4 -0.9（42/90 条更高），N = 5 -4.7（35/90 条更高），N = 6 -8.7（27/90 条更高），N = 8 -8.9（27/90 条更高），N = 10 -9.5（27/90 条更高）。
  - 按正式选法每个 N 各选一条：最差起点年化最高的是 N = 5 的 DB-K2-b1（年化 +31.6%，最差起点 +24.5%，信息比率 1.17）；N = 1 选的是 DB-K1-b6（年化 +33.7%，最差起点 +24.4%，信息比率 1.05），最差起点只差不到 1 个百分点，算打平。把 N 当参数一起选是在全样本上多挑一次，只作参考。
- 20 万 全网格，超额比 N = 1 的变化（中位数）：N = 2 -0.4（37/90 条更高），N = 3 -1.7（23/90 条更高），N = 4 -4.4（11/90 条更高），N = 5 -7.8（5/90 条更高），N = 6 -9.6（1/90 条更高），N = 8 -11.5（1/90 条更高），N = 10 -12.3（1/90 条更高）。
  - 按正式选法每个 N 各选一条：信息比率最高的是 N = 1 的 DB-K30-b8（年化 +29.7%，最差起点 +14.1%，信息比率 2.52）。把 N 当参数一起选是在全样本上多挑一次，只作参考。
- 机制（2 万 DB-K2-b6，N = 1）：85% 的成交不到 4 天就卖了。卖掉的票如果接着拿到买入后第 4 天开盘，相对同期准入池平均还能多赚 0.31% [+0.12, +0.50]；同一个开盘换上的新票同一段平均 +0.56%，比卖掉的那只（+0.31%）多 +0.25% [+0.03, +0.45]，换上的新票更好：早卖赚的是换仓，不是躲开下跌。
- 机制（20 万 DB-K30-b4，N = 1）：75% 的成交不到 4 天就卖了。卖掉的票如果接着拿到买入后第 4 天开盘，相对同期准入池平均还能多赚 0.22% [+0.15, +0.30]；同一个开盘换上的新票同一段平均 +0.48%，比卖掉的那只（+0.22%）多 +0.26% [+0.17, +0.34]，换上的新票更好：早卖赚的是换仓，不是躲开下跌。
- 2 万：按预注册的标准，维持现在的规则（不加最少持有天数）。
- 20 万：按预注册的标准，维持现在的规则（不加最少持有天数）。

- 不限价：16 项逐项一样（N = 1、不剔退市整理期；四条主规则在 2 万、20 万的全期数字和逐日收益，加上十年实验存了的 2 万换起点）。
