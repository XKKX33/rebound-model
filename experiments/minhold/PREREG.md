# 最少持有天数：只改持股规则的十年回测（预注册，2026-11-01 00:20，跑之前写）

## 问题

用户问：反弹模型的训练目标是五天收益（o1o5：T+1 开盘买、T+5 开盘卖，持有 4 个开市日），
现在的持股规则会不会卖得太早；加一条"每只票最少持有 N 天"的规则，收益怎样。模型权重和打分都已经有了，只改持股规则做回测。

现状：正式推荐的规则都是 DB（每日调仓带缓冲：最多 K 只，前一天排名掉出 b·K 名就在开盘卖）。卖出条件只要求
"不是当天买的"，所以可以拿 1 天就卖。十年实验存的结果里平均持有天数：2 万推荐 DB-K2-b6 是 2.3 天，
20 万推荐 DB-K30-b4 是 3.2 天，都短于标签的 4 天。

## 唯一的改动

"持有天数" = 卖出日 − 买入日（开市日下标之差；停牌的日子照算）。T+1 开盘买、T+5 开盘卖 = 4 天。

DB 的卖出条件从"排名掉出 b·K，且不是当天买的"改成"排名掉出 b·K，且持有天数 ≥ N"。N 天之内掉出缓冲的票照样拿着、
占着名额；到了 N 天，下一个开盘按前一天的排名照常判断（还在 b·K 名以内就继续拿）。

- N = 1 就是现在的规则（必须和十年实验存的结果逐项一样，见"核对"）。
- N = 4：最早在 T+5 开盘卖，和标签的卖点对齐。这是要检验的主假设。
- 也算 N = 2、3、5、6、8、10，只画成曲线。
- FH（固定持有）本身就是到期才卖，不受影响，不重算。

其余全部不动：模型和打分（十年实验存的每月重训 CPU 版打分，2015-01 起，3 个种子平均）、规则网格的 90 条 DB 规则、
每个行业最多 2 只、买不进顺延、成本、计分日、换起点的起点。不重训，不调参，不改特征。

## 准入池

- 主：不限价（正式系统的日常默认，十年实验 `nocap/`）。敏感性：限 70 元（十年实验主线），只算下面四条主规则。
- 剔除收盘 < 2 元；剔除退市整理期（当时名称带"退"，正式系统 2026-10-31 起的口径），选股和准入池基准都剔。
- 核对：N = 1、不剔退市整理期时，四条主规则的全期数字（2 万、20 万）和 2 万的四个起点，必须和十年实验存的结果逐项一样；
  对不上就停。

## 账户

本金 2 万、20 万；佣金万五、每笔最低 5 元，过户费十万分之一（双边），一手取整，印花税全期按现行 0.05%。
敏感性：2 万的两条主规则另算免五。

## 主比较（定死，看结果之前）

每种本金一条决定用的规则（正式系统现在的推荐）和一条参照规则：

| 本金 | 决定用 | 参照 | 正式选法看的指标 |
|---|---|---|---|
| 2 万 | DB-K2-b6（换起点最稳） | DB-K3-b16（十年实验手选） | 四个起点（2017/2019/2021/2023）的最差年化 |
| 20 万 | DB-K30-b4（信息比率） | DB-K30-b8（限价主线的推荐） | 全期超额、信息比率 |

N = 4 对 N = 1，每种本金分别判断：

- **更好**：决定用的规则，两个 N 全期（2015 起）逐日收益之差的年化，按月重抽 95% 区间下限 > 0；
  并且 90 条 DB 规则里 N = 4 的全期超额高于 N = 1 的比例 ≥ 60%；2 万另外要求最差起点年化不比 N = 1 低。
- **更差**：区间上限 < 0，并且比例 ≤ 40%。
- 其余：**分不出**，维持现状（N = 1）。

别的 N 只作曲线。看过结果再挑出来的 N，就算满足同样的条件，也只记成待验证的假设。

## 另报

1. 每个 N：四条主规则的全期年化、超额 [区间]、回撤、平均持有天数、换手、费用、平均持仓数、空仓；2 万的四个起点。
2. 每个 N：90 条 DB 规则按正式选法会选哪条（2 万：四个起点都赚、最差起点年化最高；20 万：全期信息比率最高，
   并看它四个起点赚不赚）。把 N 当成又一个可调参数一起选，是在全样本上多挑了一次，只作参考。
3. 诊断（N = 1）：主规则的成交里，持有不到 4 天就卖掉的有多少；这些票如果拿到买入后第 4 天开盘，
   从实际卖出到那天相对准入池（同期等权开盘对开盘）多赚还是少赚。只看这只票自己，不管空出来的位置买了什么，
   所以只是解释机制，结论以完整模拟为准。
